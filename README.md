# CTF Projects

A collection of Capture The Flag (CTF) challenges designed and developed by me.

This repository contains CTF challenges I have built across different areas of cybersecurity, with each challenge designed around a specific vulnerability, attack technique, or security concept.


## Challenge Categories

* Web Exploitation

* Binary Exploitation

* Reverse Engineering

* Cryptography

* Digital Forensics

* Cloud Security

* Active Directory

* Linux

* Source Code Review

## Repository Structure

Each challenge is contained in its own directory with the files required to deploy or run it.

├── challenge-02/

├── challenge-03/
